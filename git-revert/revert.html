Git Revert

Existing commit ke changes ko new commit ke through safely undo karne ka guide.

1. Git Revert Kya Hota Hai?

git revert kisi existing commit ke changes ko reverse karne ke liye ek new commit create karta hai.

Simple Definition:
Revert = Purane commit ke effect ko undo karo, lekin history ko preserve rakho.
Key Point: Revert history ko rewrite nahi karta. Ye new commit banata hai.

2. Revert Kab Use Kare?

  • Shared/public branch par wrong commit undo karna ho.
  • Production me deployed change safely reverse karna ho.
  • Team history ko preserve rakhte hue bad change remove karna ho.

3. Basic Revert

git log --oneline
git revert <commit-id>

Git selected commit ke changes ko reverse karke ek new commit create karega.

4. Real Example

A --- B --- C
          ↑
       bad commit

Agar C ko revert karein:

A --- B --- C --- R

R ek new revert commit hai jo C ke changes ko reverse karta hai.

Original C commit history me rehta hai.

5. Revert Me Conflict

Kabhi-kabhi revert ke changes current code se conflict kar sakte hain.

git revert <commit-id>
# conflict resolve karein
git add .
git revert --continue

Revert cancel karna ho:

git revert --abort

6. Multiple Commits Revert Karna

Multiple commits ko revert karne ke several approaches hain. Specific range use karte waqt commit order ko carefully samajhna zaroori hai.

git revert <oldest-commit>^..<newest-commit>
Shared branches par multiple commits revert karne se pehle history aur dependencies check karein.

7. Revert Ka Working Flow

Existing Commit→git revert→Reverse Changes→New Commit

8. Revert vs Reset

FeatureRevertReset
New commitYesNo
History rewriteNoCan rewrite local branch history
Shared branchGenerally saferRisky if commits are already shared

9. Common Mistakes

  • Revert ko reset samajhna.
  • Conflict aane par git revert --continue bhool jana.
  • Multiple commits ka order samjhe bina range revert karna.

10. Interview Questions

Q1. git revert kya karta hai?

Selected commit ke changes ko reverse karne ke liye new commit create karta hai.

Q2. Revert history rewrite karta hai?

Nahi. Original history preserve rehti hai.

Q3. Shared branch par revert kyu useful hai?

Kyuki ye new commit banata hai aur existing public history ko rewrite nahi karta.
