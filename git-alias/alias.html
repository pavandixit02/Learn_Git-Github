Git Alias

Git commands ko short aur easy banane ke liye Alias ka complete beginner-friendly guide.

1. Git Alias Kya Hota Hai?

Git Alias ek custom shortcut hota hai jo kisi Git command ke liye banaya jata hai. Agar koi Git command baar-baar type karni padti hai, to uska short name (alias) create karke command ko quickly run kar sakte hain.

Simple Definition:
Git Alias = Git command ka shortcut.

Example:

git status

Agar status ka alias st bana diya:

git st

Dono commands same kaam karengi.

2. Git Alias Ki Zarurat Kyu Hoti Hai?

Git projects me kuch commands bahut frequently use hoti hain. Alias se:

  • Typing kam hoti hai.
  • Frequently-used commands jaldi run hoti hain.
  • Developer productivity improve hoti hai.
  • Long Git commands ko short aur memorable banaya ja sakta hai.

git log --onelinegit lgShort commit history

3. Git Alias Kaise Create Kare?

Example 1: status ka alias

git config --global alias.st status

Ab aap run kar sakte hain:

git st
Result: git st internally git status ke equivalent kaam karega.

Example 2: branch ka alias

git config --global alias.br branch
git br

Example 3: checkout ka alias

git config --global alias.co checkout
git co main

4. Useful Git Alias Examples

Log ko short aur graphical banana

git config --global alias.lg "log --oneline --graph --all"

Ab:

git lg

Last commit dekhna

git config --global alias.last "log -1 HEAD"
git last

Commit shortcut

git config --global alias.cm "commit -m"
git cm "Add Docker configuration"

Switch shortcut

git config --global alias.sw switch
git sw main

5. --global Ka Matlab Kya Hai?

--global ka matlab hai ki alias current user ke Git configuration me save hoga aur us user ke repositories me available rahega. 

git config --global alias.st status

Linux par configuration commonly:

~/.gitconfig

Example configuration:

[alias]
    st = status
    br = branch
    co = checkout
    lg = log --oneline --graph --all
Note: Alias repository ke commits ya source code ko change nahi karta. Ye sirf Git command ko invoke karne ka shortcut hai.

6. Git Alias Check Kaise Kare?

Configured aliases ki list:

git config --global --get-regexp alias

Example output:

alias.st status
alias.br branch
alias.co checkout
alias.lg log --oneline --graph --all

Specific alias check karne ke liye:

git config --global --get alias.st

7. Git Alias Delete Kaise Kare?

Agar st alias delete karna hai:

git config --global --unset alias.st

Verify:

git config --global --get alias.st

Agar output nahi aata, to alias remove ho gaya hai.

8. Local Alias vs Global Alias

TypeCommandScope
Global git config --global alias.st status User ke all repositories
Local git config alias.st status Current repository
Important: --global nahi lagane par alias current Git repository ke configuration me save hota hai.

9. Git Alias Ka Working Flow

Developer → git st → Alias Lookup → status → Git Result

Jab aap git st run karte hain, Git configuration me check karta hai ki st naam ka alias defined hai ya nahi. Agar alias status ko point karta hai, to Git status command execute karta hai.

13. Common Mistakes

  1. git alias.st status likhna — ye correct syntax nahi hai.
  2. alias aur actual Git command ko confuse karna.
  3. Alias create karne ke baad verify na karna.
  4. Global aur local configuration ka difference na samajhna.
  5. Bahut confusing aliases banana jo team members ke liye difficult hon.

Correct syntax

git config --global alias.st status

14. Interview Questions

Q1. Git Alias kya hota hai?

Git command ke liye banaya gaya custom shortcut Git Alias kehlata hai.

Q2. Status command ka st alias kaise banayenge?

git config --global alias.st status

Q3. Global alias ka configuration kaha hota hai?

Linux par commonly ~/.gitconfig me.

Q4. Alias kaise delete karenge?

git config --global --unset alias.st

Q5. Global aur local alias me difference?

Global alias user ke repositories me available hota hai, jabki local alias current repository ke configuration tak limited hota hai.
