🔄 Git Restore Command

📌 What is Git Restore?

git restore is a Git command used to restore files to their previous state. It can discard unwanted changes in your working directory or restore files from another commit or branch.

🎯 Why Do We Use git restore?

  • Undo accidental changes in a file.
  • Restore deleted files.
  • Remove uncommitted modifications.
  • Recover files from a previous commit.
  • Keep your working directory clean.

⚙️ Basic Syntax

git restore <file-name>

This command restores the specified file to its last committed version.

💻 Examples

1. Restore One File

git restore index.html

Restores index.html to its last committed state.

2. Restore Multiple Files

git restore index.html style.css script.js

3. Restore All Modified Files

git restore .

Restores all modified tracked files.

4. Restore a Deleted File

git restore README.md

5. Restore a File from Another Commit

git restore --source=HEAD~1 index.html

Restores the file from the previous commit.

📖 Real-Life Example

Imagine you are writing an assignment and accidentally delete an important paragraph.

Instead of rewriting everything, you restore the previous saved version.

git restore works in the same way.

⚠️ Important Notes

  • Works only for tracked files.
  • Untracked files are not restored.
  • Discarded changes cannot be recovered unless they were committed.
  • Always verify before using git restore ..

🆚 Git Restore vs Git Checkout

Git Restore Git Checkout
Restore files only Switch branches and restore files
Modern command Older command
Safer for beginners Can perform multiple actions

💡 Best Practices

  • Run git status before using git restore.
  • Commit important work before discarding changes.
  • Use git restore . carefully.
  • Understand the difference between staged and unstaged changes.

📌 Summary

  • git restore restores tracked files.
  • It discards unwanted changes.
  • It can recover deleted tracked files.
  • It is safer and more modern than using checkout for restoring files.
  • Always check git status before restoring.
