Git Restore

Working tree aur staging area ke changes ko safely samajhne aur manage karne ka guide.

1. Git Restore Kya Hota Hai?

git restore ka main purpose working directory ya staging area me kiye gaye changes ko restore/remove karna hai.

Simple Definition:
Restore = Working tree ya staging area ke changes ko specified state par wapas lana.

Important: git restore mainly file-level changes handle karta hai. Ye commits ko delete/undo karne ke liye primary command nahi hai.

2. Restore Kab Use Kare?

  • File me galat changes kar diye aur unhe discard karna hai.
  • Staged file ko unstage karna hai.
  • File ko kisi commit ki state se restore karna hai.
Warning: Working-tree changes ko discard karne wali restore command se uncommitted work lose ho sakta hai.

3. Working Directory Changes Discard Karna

git restore filename.txt

Isse filename.txt ke unstaged changes discard hoke last committed state restore ho jayegi.

Example:

git status
git restore app.py
git status

4. Multiple Files Restore

git restore file1.txt file2.txt

Current directory ke multiple files ke changes discard karne ke liye:

git restore .
Careful: git restore . current directory ke unstaged changes discard kar sakta hai.

5. Staged File Ko Unstage Karna

git add app.py
git restore --staged app.py

Yahaan file ke changes delete nahi hote. Sirf staging area se file remove hoti hai.

Important: --staged ka use unstage karne ke liye hota hai.

6. Commit Se File Restore Karna

git restore --source=HEAD -- app.py

Isse app.py ko current HEAD commit ki state me restore kiya ja sakta hai.

Specific commit se:

git restore --source=<commit-id> -- app.py

7. Restore Ka Working Flow

File Change→git restore→Previous/Selected State

8. Restore vs Unstage

CommandMain PurposeChanges Delete?
git restore fileUnstaged changes discardYes, specified working-tree changes
git restore --staged fileUnstageNo, working changes remain

9. Common Mistakes

  • git restore file ko unstage command samajhna.
  • Uncommitted changes ka backup liye bina restore kar dena.
  • git restore . blindly run karna.

10. Interview Questions

Q1. git restore ka primary use?

Working tree ya staging area ke changes ko restore/unstage karna.

Q2. File ko unstage kaise karenge?

git restore --staged filename

Q3. Unstaged changes discard?

git restore filename
