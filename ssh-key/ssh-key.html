1. SSH Kya Hai?

SSH = Secure Shell. SSH ek secure network protocol hai jiske through tum remote computer/server ke saath encrypted connection establish karke securely authenticate aur commands/data transfer kar sakte ho.

Simple real-life analogy

Imagine ek secure building hai:

  • Server: Building
  • SSH connection: Secure entrance
  • Private key: Tumhari secret key
  • Public key: Building ke security system mein registered lock information
  • Authentication: Security verify karta hai ki tum authorized ho

SSH ka use kaha hota hai?

🐧 Linux Servers

Remote server login aur administration.

🐙 GitHub

Git repository ke saath SSH-based authentication.

☁️ Cloud

Cloud VM/instance administration.

🚀 DevOps

Automation, deployment aur server operations.

🔐 Secure Access

Password ke alternative authentication.

📦 Git

Clone, fetch, pull, push via SSH remote.

SSH basic command

ssh username@server-ip

Example:

ssh ubuntu@203.0.113.10
Important: Example IP documentation ke liye use kiya gaya hai. Apne actual server ke hostname/IP aur username ko replace karna hota hai.

2. SSH Key Kya Hoti Hai?

SSH key authentication mein normally key pair hota hai: private key + public key. Dono mathematically related hote hain, lekin private key ko secret rakhna hota hai.

Typical files

~/.ssh/
├── id_ed25519          ← Private key
├── id_ed25519.pub      ← Public key
└── known_hosts         ← Known server host keys
Golden rule: id_ed25519 private key hai. Isko GitHub, Git repository, chat, screenshot ya public repository mein upload/commit mat karo.

4. SSH Key Kaise Generate Karein?

Step 1 — Check existing SSH keys

ls -la ~/.ssh

Common output mein files jaise:

id_ed25519
id_ed25519.pub
known_hosts

Step 2 — Generate Ed25519 key

ssh-keygen -t ed25519 -C "your-email@example.com"

Command ke parts:

PartMeaning
ssh-keygenSSH key pair generate/manage karne ka command.
-t ed25519Ed25519 key type select.
-CComment add karta hai; identification ke liye useful.

Step 3 — File location

Prompt kuch is type ka aa sakta hai:

Enter file in which to save the key:
/home/username/.ssh/id_ed25519

Single GitHub account ke simple setup mein default location accept kar sakte ho.

Step 4 — Passphrase

Enter passphrase:
Enter same passphrase again:
Recommended: Private key ko passphrase se protect karna useful hai. Agar private key file accidentally copy ho bhi jaye, passphrase ek additional protection layer provide karti hai.

Step 5 — Verify generated files

ls -la ~/.ssh
ls -l ~/.ssh/id_ed25519*

Step 6 — Public key display

cat ~/.ssh/id_ed25519.pub

Public key normally ek single line hoti hai, for example:

ssh-ed25519 AAAA... your-email@example.com
Only .pub key share karo. id_ed25519 ko kabhi copy/share/upload mat karo.

RSA key generation — compatibility case

ssh-keygen -t rsa -b 4096 -C "your-email@example.com"

New setups mein Ed25519 generally simpler modern choice hai; RSA tab use karo jab compatibility requirement ho.

5. GitHub ke Saath SSH Key Setup

Step 1 — Generate key

ssh-keygen -t ed25519 -C "your-email@example.com"

Step 2 — Public key copy karo

Linux clipboard tools environment-dependent hote hain. Terminal mein safe/simple method:

cat ~/.ssh/id_ed25519.pub

Output ki complete line copy karo.

Step 3 — GitHub account mein public key add karo

  1. GitHub account open karo.
  2. Settings open karo.
  3. SSH and GPG keys section par jao.
  4. New SSH key choose karo.
  5. Descriptive title do, e.g. Dell Ubuntu.
  6. Public key paste karo.
  7. Save/Add SSH key.

Step 4 — SSH connection test

ssh -T git@github.com

First connection par host authenticity confirmation prompt aa sakta hai. Expected GitHub authentication response ko dekhkar verify karo ki authentication successful hai.

Step 5 — Git remote SSH format

git@github.com:USERNAME/REPOSITORY.git

Check current remote:

git remote -v

HTTPS remote ko SSH mein change karna

git remote set-url origin git@github.com:USERNAME/REPOSITORY.git

Verify:

git remote -v

Then normal Git commands

git add .
git commit -m "Update project"
git push origin main
Important: Ek baar SSH authentication correctly configured ho jaye, Git remote SSH URL use karke push/pull/clone operations ke liye normal Git workflow continue kar sakte ho.

Which one should you understand as a DevOps learner?

Dono ko samjho. HTTPS networking environments mein common aur convenient ho sakta hai; SSH keys Git/GitHub, Linux administration, cloud VMs, automation aur DevOps workflows mein important concept hain.

Important: SSH aur HTTPS dono secure protocols/transport mechanisms hain, lekin “SSH key” ek authentication mechanism hai. HTTPS ko SSH key ke saath compare karna technically “HTTPS-based Git authentication vs SSH-based Git authentication” comparison hai.

7. ssh-agent — Private Key Management

Why ssh-agent? Agar private key passphrase protected hai, to ssh-agent loaded key ko session ke dauran manage kar sakta hai, jisse har SSH operation par passphrase repeatedly enter karne ki need kam ho sakti hai.

Start agent

eval "$(ssh-agent -s)"

Add key

ssh-add ~/.ssh/id_ed25519

List loaded keys

ssh-add -l

Remove all loaded keys

ssh-add -D
CommandPurpose
ssh-agentAgent process manage.
ssh-addPrivate key agent mein load.
ssh-add -lLoaded identities list.
ssh-add -DAll identities remove from agent.

8. Multiple SSH Keys — GitHub, Work, Personal

Agar tumhare paas multiple GitHub accounts/services hain, separate keys rakhna useful ho sakta hai. Example: 

~/.ssh/
├── id_ed25519_personal
├── id_ed25519_personal.pub
├── id_ed25519_work
├── id_ed25519_work.pub
└── config

Generate separate keys

ssh-keygen -t ed25519 -C "personal@example.com" -f ~/.ssh/id_ed25519_personal

ssh-keygen -t ed25519 -C "work@example.com" -f ~/.ssh/id_ed25519_work

SSH config

Host github-personal
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_personal
    IdentitiesOnly yes

Host github-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work
    IdentitiesOnly yes

Use personal alias

git clone git@github-personal:PERSONAL_USER/repo.git

Use work alias

git clone git@github-work:WORK_USER/repo.git
Concept: Host alias Git remote mein use hota hai, but actual HostName GitHub hi ho sakta hai. Isse SSH ko correct private key select karne mein help milti hai.

Project remote set karna

git remote set-url origin git@github-personal:USERNAME/REPO.git

9. SSH Troubleshooting

Error: Permission denied (publickey)

git@github.com: Permission denied (publickey).

Possible causes:

  • Public key GitHub account mein add nahi hui.
  • Wrong private key use ho rahi hai.
  • ssh-agent mein key loaded nahi.
  • SSH config wrong hai.
  • Git remote wrong hai.

Debug command

ssh -vT git@github.com

More detailed:

ssh -vvT git@github.com

Check keys

ls -la ~/.ssh
ssh-add -l

Check remote

git remote -v

Test specific key

ssh -i ~/.ssh/id_ed25519 -T git@github.com

Check SSH config

cat ~/.ssh/config

Permissions on Linux

chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
Never do this: private key ko chmod 644 karke world-readable mat rakho. Private key permissions restrictive honi chahiye.

Error: Repository not found

SSH authentication successful hone ke baad bhi repository access fail ho sakta hai agar: wrong repository path, wrong GitHub account, ya insufficient repository permissions hain.

11. SSH Security Best Practices

  • Private key kabhi share mat karo.
  • Private key ko public Git repository mein commit mat karo.
  • Strong passphrase use karo.
  • Need ke according separate keys use karo.
  • Unknown host-key warnings ko blindly ignore mat karo.
  • Unused/compromised keys ko revoke/remove karo.
  • Production servers par password login/SSH configuration ko organization policy ke according harden karo.
  • Least privilege follow karo.
  • Private keys ka secure backup strategy rakho; unencrypted copies casually cloud/chat mein mat upload karo.
Most important: Public key share karna generally expected hai; private key share karna authentication secret compromise kar sakta hai.

12. Interview Questions

Q1. SSH kya hai?

Secure Shell, encrypted remote communication/authentication ke liye protocol.

Q2. SSH key pair kya hota hai?

Public key + private key ka cryptographic pair.

Q3. Public aur private key mein difference?

Public key remote service par register hoti hai; private key secret client-side credential hoti hai.

Q4. GitHub mein SSH key kyu use karte hain?

Git operations ko SSH-based key authentication ke through authenticate karne ke liye.

Q5. Ed25519 kya hai?

Modern public-key signature algorithm/key type jo SSH key generation mein commonly use hota hai.

Q6. ssh-keygen kya karta hai?

SSH key pair generate/manage karta hai.

Q7. ssh-agent?

Loaded private keys ko session ke dauran manage/use karne mein help karta hai.

Q8. known_hosts?

SSH known server host keys/identities ka local record.

Q9. HTTPS vs SSH Git remote?

HTTPS remote HTTPS-based authentication use karta hai; SSH remote SSH key-based authentication use karta hai.

Q10. Permission denied (publickey) kaise troubleshoot?

Public key registration, private key selection, ssh-agent, SSH config, remote URL aur verbose SSH logs check karo.

Q11. Multiple GitHub accounts kaise manage karoge?

Separate keys + ~/.ssh/config host aliases use kar sakte ho.

Q12. Private key GitHub par upload karni hai?

No. GitHub ko public key add karni hoti hai; private key secret rehti hai.
