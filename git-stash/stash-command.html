Git Stash

Temporary changes ko safely side me rakhna, clean working tree banana, branch switch karna aur baad me changes wapas lana — Git Stash isi problem ko solve karta hai.

1. Git Stash kya hota hai?

Git Stash Git ka mechanism hai jo aapke current working changes ko temporarily save karke working directory ko clean state me la sakta hai.

Simple language me:

“Kaam adhura hai, commit nahi karna, lekin mujhe abhi branch switch ya koi urgent Git operation karna hai — changes ko temporarily side me rakh do.”

Example: Aap feature par kaam kar rahe ho, lekin suddenly production bug fix karne ke liye main branch par jaana hai. Aap adhura code commit nahi karna chahte. Yahan git stash useful hai.

2. Git Stash ki zarurat kyu padti hai?

🔀 Branch switch

Current changes ko commit kiye bina temporarily side me rakhkar doosri branch par kaam kar sakte ho.

🚨 Urgent bug fix

Feature work ko temporarily park karke hotfix branch par switch kar sakte ho.

🧹 Clean working tree

Git commands ya workflows jahan clean working tree useful hai, wahan stash help karta hai.

💾 Temporary checkpoint

Changes ko permanent commit banaye bina temporary snapshot ki tarah store kar sakte ho.

5. Basic Git Stash Command

5.1 Current changes stash karna

git stash

Ye commonly tracked files ke working changes ko stash karke working tree ko clean karta hai.

5.2 Recommended explicit form

git stash push

Modern Git workflows me git stash push explicit aur readable form hai.

5.3 Message ke saath stash

git stash push -m "WIP: login page changes"

Message dene se baad me stash identify karna easy hota hai.

5.4 Stash list dekhna

git stash list

Example:

stash@{0}: On feature/login: WIP: login page changes
stash@{1}: On main: WIP: navbar update
stash@{2}: On dev: API integration work
Index samjho: stash@{0} newest stash hota hai. Number badhne par older stash entries hoti hain.

5.5 Stash details dekhna

git stash show
git stash show -p

-p patch/diff details show karta hai.

5.6 Latest stash apply karna

git stash apply

Default me latest stash ko apply karta hai, lekin stash entry ko delete nahi karta.

5.7 Specific stash apply karna

git stash apply stash@{1}

5.8 Latest stash pop karna

git stash pop

pop changes ko apply karta hai aur successful application ke baad stash entry ko remove karne ki koshish karta hai.

5.9 Specific stash pop

git stash pop stash@{1}

5.10 Stash delete karna

git stash drop stash@{1}

5.11 Latest stash delete karna

git stash drop

5.12 All stashes delete karna

git stash clear
Warning: git stash clear sabhi stash entries remove kar deta hai. Is command ko carefully use karo.

6. Most Important Workflow: Stash → Switch → Work → Return → Apply

Scenario

Aap feature/login par kaam kar rahe ho. Changes incomplete hain. Suddenly main par urgent work karna hai.

# 1. Current status check
git status

# 2. Current changes temporarily save
git stash push -m "WIP: login feature"

# 3. Branch switch
git switch main

# 4. Urgent work
# ... edit files ...

# 5. Apna feature branch wapas
git switch feature/login

# 6. Stash list
git stash list

# 7. Changes restore
git stash pop
Mental formula:
Work → Stash → Switch → Fix → Switch Back → Apply/Pop

7. apply vs pop

CommandChanges Restore?Stash Entry Remove?Use Case
git stash applyYesNoSafe restore; stash ko backup ki tarah rakhna
git stash popYesUsually yes after successful applicationRestore karke stash list se hata dena
Agar conflict ho jaye, apply useful ho sakta hai kyunki stash entry preserve rehti hai. pop ke behavior ko conflict ke case me blindly assume mat karo; Git successful application ke baad hi stash ko remove karta hai.

8. Tracked aur Untracked Files ka Important Concept

8.1 Default stash

git stash push

Default behavior me tracked files ke changes stash hote hain. New/untracked files automatically include nahi hote.

8.2 Untracked files bhi stash karna

git stash push -u

-u = --include-untracked

8.3 Ignored files bhi include karna

git stash push -a

-a = --all. Isme untracked aur ignored files bhi include ho sakti hain.

CommandTracked ChangesUntrackedIgnored
git stash push✅❌❌
git stash push -u✅✅❌
git stash push -a✅✅✅
Ignored files ko stash karte waqt carefully socho, kyunki -a build artifacts, generated files ya local ignored data ko bhi stash scope me la sakta hai.

9. Staged vs Unstaged Changes

Git stash working tree ke saath staging/index state ko bhi preserve kar sakta hai. Agar aapko staged state ko bhi restore karna ho to --index useful hai.

git stash push -m "WIP"
git stash apply --index
Note: --index ka purpose sirf files restore karna nahi, balki original staged state ko bhi restore karne ki koshish karna hai.

10. Specific Files ko Stash karna

Aap poori working tree ke bajay selected paths ko stash kar sakte ho.

git stash push -- path/to/file.txt

git stash push -- src/app.js src/style.css

Interactive selection ke liye:

git stash push -p

-p interactive patch mode deta hai, jisse aap hunks select kar sakte ho.

11. Stash Apply karte waqt Conflict

Stash jis state se banaya gaya tha aur current branch ki state me changes overlap kar sakte hain. Aise case me conflict aa sakta hai.

git stash apply stash@{0}

Agar conflict aaye:

git status

Conflicted files open karke conflict markers resolve karo:

<<<<<<< HEAD
current branch changes
=======
stashed changes
>>>>>>> stash

Resolution ke baad:

git add <resolved-file>
git status

Phir normal commit workflow continue kar sakte ho:

git commit -m "Resolve stash conflict"
Important: Stash apply conflict ko git merge --abort ya git rebase --abort samajhna galat hai. Stash application ko undo karne ke liye context-specific manual cleanup ya known restore workflow ki zarurat ho sakti hai.

12. Advanced Stash Commands

12.1 Stash with a clear message

git stash push -m "WIP: payment API integration"

12.2 Latest stash inspect

git stash show stash@{0}
git stash show -p stash@{0}

12.3 Stash ko new branch me convert karna

git stash branch feature/payment stash@{0}

Ye useful hai jab stash ko jis base par create kiya gaya tha us context me directly new branch par continue karna ho.

12.4 Stash entry remove

git stash drop stash@{0}

12.5 All stash entries remove

git stash clear

12.6 Stash ref details

git rev-parse --verify refs/stash

Advanced Git understanding ke liye refs/stash ek useful concept hai. Stash entries reflog-like reference ke through track hoti hain.

13. Git Stash Internally kaise kaam karta hai?

Beginner level par aap ise temporary storage samjho. Internally Git stash ko Git objects aur a stash reference ke through manage karta hai.

Stash commit-like objects/snapshots ke form me current state ko preserve kar sakta hai, jisse baad me changes restore kiye ja sakte hain.

17. DevOps me Git Stash ka Use

☁️ Infrastructure

Terraform/IaC changes ke beech urgent branch switch karna ho to temporary WIP changes park kiye ja sakte hain.

🐳 Docker

Dockerfile, Compose ya deployment config par incomplete changes ko temporarily stash karke hotfix inspect kiya ja sakta hai.

⚙️ CI/CD

Pipeline configuration par local experiments ko temporarily side me rakhkar stable branch ke workflow par kaam kar sakte ho.

☸️ Kubernetes

Manifest changes incomplete hon aur kisi aur environment/config branch par switch karna ho to stash useful ho sakta hai.

🔧 Configuration

Environment/config files ke tracked modifications ko temporarily park kiya ja sakta hai.

🚨 Hotfix

Feature development se urgent production fix workflow par temporarily switch karna common scenario hai.

Security: Stash me sensitive local changes aa sakte hain. Secrets, passwords, tokens aur private keys ko Git me store karna avoid karo. .gitignore aur proper secret-management tools use karo.

19. Professional Workflow Example

# You are working on feature
git switch feature/login

# See current work
git status
git diff

# Save incomplete work
git stash push -u -m "WIP: login validation"

# Move to hotfix
git switch main
git pull --ff-only

# Create hotfix branch
git switch -c hotfix/navbar

# Fix issue
git add .
git commit -m "Fix navbar issue"

# Return to feature
git switch feature/login

# Check available stash
git stash list

# Restore safely
git stash apply stash@{0}

# Inspect result
git status
git diff

# After confirming everything
git stash drop stash@{0}

20. Common Mistakes

❌ Mistake 1: Untracked file automatically stash ho jayegi

Default stash me new untracked file usually include nahi hoti.

Use:

git stash push -u

❌ Mistake 2: pop ko backup samajhna

pop successful restore ke baad stash entry remove kar sakta hai. Important stash ke liye pehle apply use karna safer ho sakta hai.

❌ Mistake 3: Stash list clean na rakhna

Bahut saare unnamed stashes confusing ho sakte hain.

Better:

git stash push -m "WIP: payment API"

❌ Mistake 4: git stash clear casually run karna

Ye sab stash entries remove kar deta hai.

❌ Mistake 5: Stash ko remote backup samajhna

Stash primarily local workflow tool hai. Team ke saath work share karne ke liye branch + commit + push better approach hai.

22. Git Stash Interview Questions

Q1. What is git stash?

Git stash uncommitted work ko temporarily store karke working tree ko clean karne ka mechanism hai.

Q2. git stash kab use karte hain?

Jab current changes incomplete hon aur commit kiye bina branch switch ya urgent task perform karna ho.

Q3. git stash apply vs git stash pop?

apply stash ko apply karta hai aur entry retain karta hai. pop apply karke successful application ke baad entry remove kar sakta hai.

Q4. Untracked files stash kaise karenge?

git stash push -u ya git stash push --include-untracked.

Q5. Ignored files bhi stash kaise karenge?

git stash push -a / --all.

Q6. Stash list kaise dekhenge?

git stash list.

Q7. Specific stash kaise apply karenge?

git stash apply stash@{1}.

Q8. Stash ko branch me directly continue kaise karenge?

git stash branch <branch-name> <stash>.

Q9. Kya stash remote repository me push hota hai?

Normal branch commits ki tarah stash workflow remote collaboration ke liye designed nahi hai. Stash primarily local temporary work storage hai.

Q10. Stash aur commit me difference?

Stash temporary WIP parking ke liye hota hai; commit project history me intentional change record karta hai.

Q11. Stash conflict kaise resolve karenge?

Conflicted files identify karo, conflict markers resolve karo, git add se resolved files stage karo, phir normal commit workflow continue karo.

Q12. git stash clear kya karta hai?

Repository ki stash entries ko clear/remove karta hai. Isliye carefully use karna chahiye.

25. Best Practices

  • Temporary work ke liye stash use karo; long-term work ke liye commits/branches use karo.
  • Important stash ko meaningful message do.
  • Restore karne se pehle git stash list check karo.
  • Important stash ke liye apply ko pop se prefer kar sakte ho.
  • Untracked files ke liye -u ya ignored files ke liye -a consciously choose karo.
  • git stash clear carefully use karo.
  • Stash me secrets accidentally store karne se bacho.
  • Team collaboration ke liye branch + commit + push workflow use karo.
